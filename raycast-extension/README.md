# Burrito for Raycast

Select files in Finder, open Raycast, then run `PNG`, `WebP`, `PDF`, `WebM`, or `MP4`. Burrito processes the selection using the current compression preset and copies every successful result to the clipboard.

## Install for development

```bash
cd raycast-extension
npm install
npm run dev
```

The matching Burrito build from this repository must be installed and running.
